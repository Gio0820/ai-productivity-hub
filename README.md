# AI Productivity Hub

Build a modern, responsive SaaS-style web app called AI Workplace Productivity Assistant for professionals.

Core Features

Meeting Notes Summarizer: Summarize lengthy meeting notes and extract action items, decisions, and deadlines.

AI Task Planner: Generate daily/weekly schedules and prioritize tasks effectively.

AI Research Assistant: Summarize topics/articles and provide useful insights and recommendations.

Design & UX

Professional dashboard layout with sidebar navigation.

Responsive for desktop and mobile.

Clear input and AI-generated output sections.

Clean, modern, intuitive SaaS UI.

Use purple as the primary colour, with contrasting pink accents.

Add a subtle rose-pattern watermark to the background.

Include loading states, empty states, and clear action buttons.

Add a visible Responsible AI disclaimer explaining that AI-generated content should be reviewed before use.

Scope & Access

No backend, authentication, sign-in, or registration.

Users should access and use the application immediately as guests.

All task-related responses and outputs must be AI-generated based on the user's input. Do not use generic, static, or pre-written responses.

Do not add unnecessary features or complexity.

Keep the application focused on the frontend experience and AI-generated responses.

Make the interface polished, professional, intuitive, and easy to use.

Prioritize functional AI interactions and a smooth user experience over extra features.
