# AI Workplace Productivity Assistant

## Project Overview

**AI Workplace Productivity Assistant** is a modern, responsive web application designed to help professionals improve workplace productivity using AI.

The application provides AI-powered tools for summarizing meeting notes, planning tasks, and conducting research. It is designed with a clean and professional SaaS-style interface that allows users to access the tools without signing in or creating an account.

## Features Implemented

### 📝 Meeting Notes Summarizer

* Summarizes lengthy meeting notes.
* Extracts important **action items**.
* Identifies key **decisions**.
* Extracts relevant **deadlines**.
* Generates responses based on the user's provided meeting notes.

### 📅 AI Task Planner

* Generates personalized **daily and weekly schedules**.
* Prioritizes tasks effectively.
* Organizes tasks based on the user's input.
* Provides AI-generated planning recommendations.

### 🔎 AI Research Assistant

* Summarizes topics and articles.
* Provides AI-generated insights.
* Generates research recommendations based on user input.

### 🎨 User Interface

* Modern SaaS-style dashboard.
* Responsive **desktop and mobile** design.
* Sidebar navigation.
* Purple primary colour scheme with pink accents.
* Subtle rose-pattern background watermark.
* Clear input and AI-generated output sections.
* Loading and empty states.
* Responsible AI disclaimer.

## Setup Instructions

### 1. Clone the Repository

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
```

### 2. Navigate to the Project Folder

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install Dependencies

If the project uses Node.js:

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application should then be available through the local development URL provided in your terminal.

### 5. Open the Application

Open the provided local URL in your web browser and start using the AI Workplace Productivity Assistant.

## Access

The application does **not require user registration, authentication, or sign-in**. Users can access the application directly as guests.

The application focuses on the frontend experience and AI-generated responses. Task-related outputs are generated based on the user's input rather than using generic or pre-written responses.

## Responsible AI

AI-generated content may contain inaccuracies or incomplete information. Users should review and verify AI-generated outputs before using them for important workplace, business, academic, or professional decisions.
